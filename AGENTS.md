# Repository instructions

- When you write code comments, documentation, or commit messages, prefer ASD-STE100 issue 9 compliant text.
- For each GitLab merge request reference, use the full canonical URL. This rule also applies to repeated references and merge order instructions. Do not use a bare merge request number.
- The first OpenCode app version is `0.0.1`. For each commit, increase the patch version in `opencode/config.yaml`. Keep the app version separate from the tool versions in `opencode/mise.toml`.
- For an OpenCode release, update `opencode/CHANGELOG.md` with the app version.
